## 3. Шаги публикации (владелец)

1. Создать репозиторий на GitHub, загрузить содержимое папки проекта так, чтобы `index.html`, `sw.js`, `manifest.webmanifest`, `.nojekyll` лежали в корне.
2. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
3. Через 1–2 минуты открыть `https://<аккаунт>.github.io/<репозиторий>/` на компьютере: приложение открывается, в «Справке» внизу — «Версия v5-1 · данные обновлены: 13 сентября 2026».
4. Вписать фактический адрес в раздел 5 этого документа.
