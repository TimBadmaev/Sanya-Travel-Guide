# Данетки: 100 историй

Бесплатная игра для компании в формате «Да / Нет / Не имеет значения».

- 100 авторских историй (по 20 в пяти категориях)
- 2 подсказки и развязка у каждой
- Пульт ведущего: Да, Нет, Не имеет значения
- Таймер, счётчик, фильтры, избранное, пройденные истории
- Работает без интернета после первого открытия по HTTPS или как отдельный HTML-файл
- Все данные хранятся локально на устройстве, аккаунт не нужен

**Как играть:** ведущий изучает развязку и зачитывает только условие. Игроки задают вопросы, ведущий отвечает «Да», «Нет» или «Не имеет значения».
