# Данетки 6.0: игровые вечера

Полностью бесплатная веб-игра/PWA без рекламы. 280 загадок: 11 тематических наборов по 25 и 5 бонусных серийных историй. Оптимизирована для iPhone, Android и больших экранов.

## Быстрый старт

1. Выбрать готовый игровой вечер (8 вариантов: разминка, весёлая компания, детектив, семья, вдвоём, тайны, эксперты, мини-сериал).
2. Ведущий читает условие, компания задаёт вопросы. Ответы ведущего: Да, Нет, Не имеет значения.
3. Если нужно, используются две подсказки. После разгадки отмечается результат партии.
4. Данные остаются на устройстве. Доступен экспорт/импорт резервной копии.

## Реализовано

- Готовые игровые вечера с постепенным повышением сложности, проверенные кодом на всех устройствах сценарии.
- Сохраняется прежний прогресс по исходным ID 1–275. Своих загадок может быть сколько угодно до локального лимита 100.
- Безопасный фильтр по ключевым словам: **не заменяет ручное возрастное ревью**.
- Скрытый ответ, подсказки, кнопки ответов ведущего, режим экрана игрока без развязки, ссылка на загадку без спойлеров.
- Текстовый автоответчик: **только точное совпадение со справочными вопросами, не ИИ**, неизвестные вопросы не решает.
- Оценки и замечания на истории, добровольная локальная аналитика игровых действий, выгрузка результатов в JSON.
- Локальный редактор своих загадок. Общий каталог нельзя пополнять без модерации разработчиком.
- Установка PWA и офлайн-режим после первой загрузки; ручное и автоматическое обновление через service worker.

## Ограничения

GitHub Pages обслуживает статический сайт, но не предоставляет реальный многопользовательский сервер. Ссылка игрока создаёт **отдельный экран без развязки**, но **не синхронизирует действия между телефонами**. Экспериментальный backend для онлайн-комнат подготовлен в `room_server/`; он не развёрнут и не подключён к публичному приложению. Чтобы задействовать его, нужно выбрать хостинг с HTTPS и протестировать отказоустойчивость, безопасность, модерацию и лимиты. ИИ-ведущий, аккаунты, облачная синхронизация и общая аналитика также пока требуют отдельной инфраструктуры.

## Разработка

Исходные данные `stories.json` (280 историй) и код `build_v6.py` доступны в архиве проекта. Генерируемый `index.html` содержит данные внутри, чтобы работать даже в автономном режиме.

Проверки:

```bash
python audit.py
python test_v6.py
cd room_server && python test_rooms.py
```

`test_v6.py` включает реальные сценарии Playwright на ширине 320/390/1280 px; ограничения среды не позволяют выполнить проверки публичного URL и установленного iOS PWA из контейнера.
