# Данетки: 275 историй (v5)

11 тем по 25 историй. Сначала выберите сложность: «По нарастающей», «Новичок», «Опытный», «Эксперт». Затем тему и нажмите «Начать игру». В режиме по нарастающей истории идут от лёгких к сложным. В каждой истории есть две подсказки, скрытая развязка и кнопки «Да», «Нет», «Не имеет значения».

Прогресс и избранное сохраняются локально, прежний ключ `danetki-curated-v2-progress` сохранён.

Онлайн: https://timbadmaev.github.io/Sanya-Travel-Guide/danetki/

Офлайн: установленная PWA работает через sw.js; отдельный index.html работает локально.
