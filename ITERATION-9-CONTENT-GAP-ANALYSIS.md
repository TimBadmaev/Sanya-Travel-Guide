## A. 5 главных content gaps

### Gap 1 — Еда: 0 verified записей

- **Проблема:** архитектура (`food.json`, загрузчик, UI, роутинг, taxi-guard) полностью готова и протестирована, но пользователь видит только честный empty state.
- **Почему важна туристу:** «где поесть» — один из самых частых бытовых вопросов, особенно вечером рядом с отелем.
- **Какой контент нужен:** минимум 1–2 verified точки питания рядом с Ялунванем — сеть Diadia Coconut Chicken (выбрать и подтвердить одну конкретную точку) и/или фудкорт «Дунжун» (亚龙湾东榕美食广场, с исправленным названием — не «Дунгуань»).
- **Можно ли без нового research:** частично — кандидаты и адреса уже найдены, но нужен точечный geocoding-проход (координаты у всех 4 записей сейчас `null`).
- **Сложность:** medium.

### Gap 2 — Вечер рядом с местом проживания (Ялунвань)

- **Проблема:** единственный кандидат на вечернюю жизнь в самом Ялунване (`bohou-village`) — draft из-за координаты, которую не удаётся подтвердить дистанционно; альтернативный кандидат (торговая улица/площадь Байхуагу) не имеет карточки вообще, хотя `plan.json` уже на неё текстом ссылается.
- **Почему важна туристу:** это прямое ядро гипотезы H-02 — вечер у отеля, а не только «куда съездить на день».
- **Какой контент нужен:** координата `bohou-village` (ручное действие) и/или карточка Байхуагу при более сильном источнике, чем уже найденный.
- **Можно ли без нового research:** нет для `bohou-village` (нужен ручной снимок координаты); частично для Байхуагу (нужен источник лучше уже найденного).
- **Сложность:** medium–large.

### Gap 3 — Незакрытые практические правила («что нельзя делать»)

- **Проблема:** портретные права/фото людей исследованы, но не оформлены как карточка; храмовый этикет Наньшаня явно заблокирован отсутствием официального регламента; карточка «Курение» содержит нерабочую ссылку-источник (P2 из QA).
- **Почему важна туристу:** цена ошибки в LEGAL/SAFETY-контенте выше, чем в обычной карточке места — это отмечено ещё в самом research (`ITERATION-8-NEXT-CONTENT-RESEARCH.md`).
- **Какой контент нужен:** новая verified-карточка «Фото людей»; решение по Наньшаню (публиковать с явной пометкой «этикет, не закон», либо не публиковать); рабочий `url` (или вторичный источник) для «Курения».
- **Можно ли без нового research:** да — весь материал уже собран и оценён по качеству источника.
- **Сложность:** small.

### Gap 4 — Короткие/лёгкие сценарии рядом с проживанием

- **Проблема:** в радиусе, реалистичном для прогулки без машины от Ялунваня, verified-вариантов мало; три близких к завершению draft-кандидата (Linchunling, Atlantis, Paddy Field) держатся на одном явном факте каждый.
- **Почему важна туристу:** это часть той же гипотезы H-02 — короткое окно свободного времени рядом с отелем, не только «выезд на целый день».
- **Какой контент нужен:** не новые кандидаты, а решения/довершение уже найденных фактов — стандарт точности координаты для Linchunling, повторная попытка (или решение публиковать без `hours`) для Atlantis, календарная перепроверка Paddy Field после 08.03.2026.
- **Можно ли без нового research:** да в основном — это продуктовые решения и ожидание даты, не поиск.
- **Сложность:** small на запись, но растянуто во времени (Paddy Field).

### Gap 5 — Бренд-специфичный шоппинг застрял на координатах

- **Проблема:** UNIQLO и оба Nike и adidas — координаты уровня «один агрегатор», не проходят порог «минимум два независимых источника для критичного факта»; два раунда research уже потрачены на эту задачу с убывающей отдачей.
- **Почему важна туристу:** ниже приоритета остальных — общий сценарий «где купить нужное» уже закрыт тремя verified ТЦ; это точность, а не новый сценарий.
- **Какой контент нужен:** вторая независимая координата на каждый объект (маловероятно найти дистанционно — см. раздел «Что не делать»).
- **Можно ли без нового research:** нет, и дальнейший research, вероятно, не даст результата — это, по сути, вопрос про то, сколько ещё сюда вкладывать, а не про поиск.
- **Сложность:** small по объёму на попытку, но с высоким риском нулевой отдачи.
