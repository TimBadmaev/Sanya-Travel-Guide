**Вывод:** провалы вызывает сам тест — частые сообщения старому воркеру откладывают активацию нового. Продукт шлёт `GET_VERSION` один раз при открытии «Справки». **Дефектом продукта не считается**, но обновление на реальном телефоне всё равно нужно проверить вручную (M-45, M-46).

## 4. Аудит по разделам задания (кратко, с уровнем доказательности)

**A. Первый запуск.** Без `stg:trip` → `replace("#/settings?first=1")`, «Пропустить всё» создаёт ключ [A]. Медленная сеть: у каждого экрана есть loading-состояние, JSON грузятся параллельно через Promise-кэш [S]. Первый визит без сети: SW ещё нет → браузерная ошибка (ожидаемо) [S]. Холодный офлайн после одной загрузки онлайн — работает [A].

**B. «Сейчас».** Состояние поездки — по датам `stg:trip`; блок «Сегодня по плану» — по периоду `plan.json` (13–26.11.2026). Это **два независимых источника дат** [S]: при других датах в настройках блок плана не появится. «Сегодня» — локальная дата устройства (`getTodayIso`) [S] → часовой пояс телефона [D].

**C/D. Места и Еда.** Фильтры, подборщик, радиус, поиск, пустые состояния, карточки и таксист покрыты автотестами [A]. Состояние поиска и Nearby живёт только в замыкании экрана и теряется при Back [A, D-03]. У Еды нет «плана» и «избранного» — так задумано (PRODUCT 9.6.4).

**E. GPS.** `getCurrentPosition({enableHighAccuracy:false, timeout:10000, maximumAge:60000})`; обработаны коды 1/2/3 и «unsupported»; структура Geolocation API используется стандартно (`coords.latitude/longitude`, `error.code`) — ничего Safari-специфичного не ломается [S]. `primeCurrentPosition()` опирается на `permissions.query({name:'geolocation'})` — Safari ≥ 16 поддерживает; при исключении тихо пропускается [S]. Позиция не хранится [S]. Карточки и Еда **ждут** `primeCurrentPosition()` до 10 с [A, D-02]. `enableHighAccuracy:false` на Android в Китае (нет сетевой геолокации Google) может давать TIMEOUT/UNAVAILABLE [D, риск R-08].

**F. Экскурсии.** 24/24 verified, все открываются, «в план» работает, дубль/лимит 3 блокируются [A]. У `yanoda-rainforest`, `binglanggu-li-miao`, `nanwan-monkey-island` нет `placeIds` (D-32) → на карточке нет ни китайского адреса, ни «Показать таксисту», ни Amap — есть только `title.zh` [S]; проверить, достаточно ли этого в поле [D].

**H. Подготовка.** 25 пунктов, отметки, прогресс, persistence [A]. Повреждённый `stg:checklist` — дефект D-01.

**I. Справка / Под рукой.** 22 карточки открываются, источники без URL рендерятся текстом [A].
